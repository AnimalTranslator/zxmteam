【如何预览 / 部署】
  1) 本地预览：解压后双击 index.html 即可（index.html 与 assets/ 必须在同一目录）。
  2) 上传到互联网：把 index.html 与 assets/ 整个目录一起上传到服务器，或使用静态托管
     （GitHub Pages、腾讯云静态网站托管、对象存储 OSS/COS 等）。
     · 素材文件名均为英文，避免中文文件名在部分服务器 / URL 编码下出现 404；
     · 页面内部全部使用相对路径（assets/...），无需修改即可直接部署；
     · 页面已声明 UTF-8，图片已压缩优化，加载体积小，不影响阅读体验。

【修改提示】
  · 更换成员照片：用同名文件覆盖 assets/ 中的对应 jpg 即可。
  · 更换标志：替换 assets/lab-logo.png（建议正方形、白底）。
